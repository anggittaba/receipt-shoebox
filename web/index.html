What is the "AI part" here?

An honest answer: in this demo it is a rule and keyword engine written in plain JavaScript (engine.js), not a trained model. It reads the receipt text and:

  • scores keywords to pick a category, with a confidence number;
  • marks a receipt billable when your note names a client;
  • flags duplicates (same shop, same total, same text, within 2 days);
  • sends unclear ones to the Review queue and asks "what was this for?".

There is a hook for a language model to refine the guess, but it is untested and switched off — no API key is used.

How well does it work?

On 40 receipts I wrote myself before writing the rules: category right 39/40, billable right 40/40, review routing right 37/40, duplicates 2/2 with no false flags. Because I wrote the test receipts myself, real receipts will score lower.

All receipts, shops and clients are made up. Built with AdminLTE 4, Bootstrap 5.3 and Chart.js (MIT licences in vendor/).
